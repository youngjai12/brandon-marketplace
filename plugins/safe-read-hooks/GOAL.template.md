# 범위

- 기간: 2015-01 ~ 2025-12
- 데이터: 로컬 parquet (data/prices/)
- 산출물: 연도별 수익률 표 + 샤프 + MDD

# 정해둔 선택

- 결측 종목: 해당 월 유니버스에서 제외

- 그 외에는 전부 적합으로 본다
